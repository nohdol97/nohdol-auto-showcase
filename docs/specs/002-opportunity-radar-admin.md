# 스펙 002: 근거 중심 기회 Radar 관리자 화면

- 상태: active
- 날짜: 2026-09-05
- 관련 ADR: `docs/adr/001-opportunity-radar-admin.md`

## 문제

가까운 사업장에 연락하기 전에 어떤 반복 업무가 실제 문제일지 알아야 하지만, 지도 리뷰를 우회 수집하는 방식은 안정적이지 않고 출처·이용조건을 보장하기 어렵다. 현재 Radar 프로토타입은 공개 장소와 직접 관찰만 다뤄서 후보마다 조사하는 노력이 남는다.

## 목표

1. `byabalone.com/admin/radar/`에서 가까운 공개 사업장을 검색하고 공개 전화번호를 남긴다.
2. 업체 소유 페이지, 공지, 예약·주문 흐름, 채용 공고처럼 출처 URL을 남길 수 있는 공개 정보로만 페인포인트 가설을 만든다.
3. 한 번 저장한 검색 조건으로 매일 한 번 자동 발굴하고, 연락 전에 확인할 근거·가설·첫 질문을 짧게 보여준다.
4. 서버 환경값 하나를 입력하는 단순한 관리자 인증을 제공하되 비밀값을 정적 파일이나 로그에 노출하지 않는다.

## 비목표

- Kakao 장소 페이지 리뷰 또는 로그인이 필요한 콘텐츠의 크롤링과 우회
- 업체에 대한 자동 전화, 문자, 이메일, 방문 예약 또는 영업 전송
- 확인되지 않은 가설을 사실이나 업체 평가로 공개하는 기능
- 설치 코드·제품키·배포 관리자 권한과의 통합

## 요구사항

### R1. 관리자 경계

관리자 화면과 API는 `/admin/radar/` 및 `/api/admin/radar/*`에 둔다. 로그인은 사용자가 입력한 값과 서버의 `RADAR_ADMIN_PASSWORD`를 상수 시간 비교하고, 성공하면 8시간 만료의 서명된 `HttpOnly`, `Secure`, `SameSite=Strict` 쿠키를 발급한다. 로그인 시도는 IP 단위로 제한한다. 비밀번호가 없거나 충분히 길지 않으면 실패를 닫힌 상태로 반환한다.

### R2. 검색 설정

관리자는 위치, 1~5개 업종 키워드, 300~5,000m 반경, 한 번에 조사할 최대 후보 수(1~10), 매일 자동 발굴 사용 여부를 저장한다. 저장값은 D1의 단일 설정 레코드가 권위가 되며 입력 오류 시 기존 값은 보존된다.

### R3. 공개 장소와 연락처

서버만 Kakao Local REST API를 호출한다. 주소 또는 위치 키워드로 중심점을 정하고 업종별 결과를 거리순으로 중복 제거한다. 저장 결과에는 Kakao 장소 ID, 상호, 업종, 공개 주소, 공개 전화번호, 거리, Kakao 장소 URL만 포함하며 키는 응답·로그에 포함하지 않는다.

### R4. 공개 근거 조사와 LLM

서버는 OpenAI Responses API의 웹 검색 도구와 구조화 출력을 사용하고 `store: false`로 호출한다. 입력은 공개 사업장 정보만 포함한다. 모델 지침은 검색 결과를 신뢰할 수 없는 관찰 자료로 취급하고, 리뷰·평점·커뮤니티 게시물을 근거로 쓰지 않으며, 확인 가능한 URL이 있는 업체 소유 페이지·공지·예약/주문 흐름·채용 공고를 우선하도록 한다.

각 후보 결과는 확인된 사실, 페인포인트 가설, 신뢰도, 근거 URL·제목·요약, 제안할 작은 도구, 첫 질문, 사실처럼 말하면 안 되는 내용을 포함한다. 또한 실제 제안으로 옮길 프로토타입 서비스의 이름, 약속할 결과, 첫 데모 범위, 고객에게 받을 입력, 효과 확인 지표를 남긴다. 근거가 부족하면 신뢰도를 낮추고 그 사실을 명시하며, 출처가 없는 주장으로 점수를 높이지 않는다.

### R5. 저장과 순위

각 실행과 후보 결과를 D1에 저장한다. 후보 순위는 모델 신뢰도와 출처 수를 사용하되, 화면에서 `공개 사실 → 가설 → 첫 질문`을 분리해 보여준다. 원문 전체, 개인 이름, 개인 연락처, 리뷰 본문은 저장하지 않는다.

### R6. 수동·자동 실행

관리자는 `지금 발굴하기`로 실행할 수 있다. 기존 5분 예약 작업은 서울 날짜 기준으로 하루 한 번만 자동 실행하며, 설정이 꺼졌거나 필수 키가 없거나 같은 날짜의 예약 실행 시도가 있으면 다시 호출하지 않는다. 실패한 자동 실행은 화면에 남기고 운영자가 수동으로 재시도할 수 있다. 중복 클릭과 동시 예약은 실행 레코드의 고유 제약으로 막는다.

### R7. 화면 상태와 안전

화면은 로그인, 미설정, 준비, 실행 중, 빈 결과, 성공, 복구 가능한 오류를 구분한다. 공개 전화번호는 복사만 제공하고 자동 연락 기능은 제공하지 않는다. 관리자 경로는 사이트맵에서 제외하고 HTML 및 응답 헤더에 `noindex, nofollow`와 `no-store`를 설정한다.

## 완료 기준

1. `[REG:radar.admin_auth]` 테스트가 잘못된 값, 누락된 환경값, 만료·변조 쿠키, 성공 쿠키, 로그아웃을 검증한다.
2. `[REG:radar.public_place_contact]` 테스트가 Kakao 응답의 공개 전화번호와 안전한 장소 URL을 매핑하고 비밀키가 결과에 없음을 검증한다.
3. `[REG:radar.evidence_analysis]` 테스트가 리뷰 출처와 잘못된 URL을 거부하고 구조화된 근거 가설을 검증한다.
4. `[REG:radar.daily_discovery]` 테스트가 서울 날짜당 한 번만 실행되는 판단을 검증한다.
5. `[REG:radar.admin_surface]` 테스트와 정적 빌드가 관리자 화면의 noindex, 인증/설정/실행/빈 결과/오류 상태와 robots 제외를 검증한다.
6. `npm run verify`가 테스트, 사이트 빌드, Worker dry-run을 통과한다.

## 미검증 범위

- 운영 Cloudflare secret·D1 migration 적용과 실제 공개 배포
- 실제 OpenAI 웹 검색 결과의 외부 페이지 정확성 및 Kakao/OpenAI 사용량
- 관리자 비밀번호 분실 복구와 다중 관리자 계정
