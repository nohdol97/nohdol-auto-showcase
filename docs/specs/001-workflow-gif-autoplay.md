# 스펙 001: 제작 사례 GIF 직접 자동 재생

- 상태: complete
- 날짜: 2026-09-03
- 관련 ADR: none

## 문제

제작 사례의 반복 GIF 위에 재생·정지 버튼이 추가되어 사례 화면보다 조작 UI가 먼저 보입니다. 방문자는 별도 조작 없이 실제 프로그램 흐름을 바로 보고 싶어 합니다.

## 목표

1. 모든 제작 사례 GIF를 브라우저의 애니메이션 이미지 동작에 맡겨 즉시 반복 재생합니다.
2. GIF 재생·정지 버튼과 상태 알림을 노출하지 않습니다.

## 비목표

- GIF 파일, 캡션, 대체 텍스트 또는 사례 진실성 문구를 변경하지 않습니다.
- 설치, 문의, 배포, D1, R2 또는 인증 권한을 변경하지 않습니다.
- 이번 변경에서 별도의 GIF 정지 수단을 제공하지 않습니다.

## 요구사항

### R1. 동적 사례 렌더링

클라이언트 렌더러는 `demoGif`를 이미지의 `src`로 직접 사용합니다. 재생 버튼, 상태 알림, 포스터 전환 및 모션 선호 감지 코드를 만들지 않습니다.

### R2. 정적 상세 경로

빌드된 상세 HTML은 GIF를 직접 참조하는 `<img>`를 포함하며, `prefers-reduced-motion`용 포스터 `<source>`를 포함하지 않습니다.

### R3. 표현과 권한 경계

재생 버튼 전용 스타일은 제거하되 일반적인 `prefers-reduced-motion` 전환 억제, GIF 대체 텍스트, 출처·제한 캡션 및 기존 설치·문의 권한은 유지합니다.

### R4. 접근성 예외

5초 이상 반복 미디어에 정지 수단을 제공하는 Abalone 인터페이스 기준에서 의도적으로 벗어납니다. 이는 사용자의 명시적인 버튼 제거 요청에 한정하며, 별도의 접근성 적합성 판단을 의미하지 않습니다.

## 완료 기준

1. 집중 회귀 테스트가 동적 렌더러와 정적 상세 HTML에서 GIF 직접 참조 및 재생 UI 부재를 확인합니다.
2. 전체 테스트, 정적 빌드, Abalone 표면 감사 및 Wrangler dry-run이 통과합니다.
3. 승인된 운영 배포 후 Cloudflare 현재 버전과 실제 상세 경로에서 버튼 부재 및 시간차 프레임 변화를 확인합니다.

## 미검증 범위

- 별도 전문 접근성 감사는 이번 범위에 포함하지 않습니다.
