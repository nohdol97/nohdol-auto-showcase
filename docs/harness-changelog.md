# 프로젝트 하네스 변경 기록

## 2026-09-07

- 사용자 요청으로 별도 Cloudflare Browser Run 진단을 배포했다. 실제 헤드리스 브라우저에서 같은 당근 업체가 HTTP 200, 고객 후기 8개·답글 5개·표시 전체 11개로 확인됐다. 4개 진단 테스트와 dry-run을 통과했으며 [실측 문서](proposals/001-daangn-cloudflare-headless.md)에 근거와 한계를 남겼다. 운영 Radar 연결은 아직 적용하지 않았다.
- 사용자 배포 요청에 따라 소스 `116c35e`를 운영 Worker `aed7f0ef-bf49-452c-bce0-66745cbc7d0b`에 반영하고 운영 트래픽 100%를 확인했다. 배포 직전 73개 테스트·빌드·dry-run이 통과했다.
- 운영 관리자 자산 3개의 SHA-256 일치, 미인증 실행 401, 390/1440px 로그인 화면, 공개 주요 경로 200과 health `ready`를 확인했다.
- 인증된 당근 표본 실행은 운영 서버 접근 차단으로 `failed · 0/1`로 종료됐다. 제한 재시도·실패 저장·안내 메시지는 확인했지만 운영 후기 수집과 실제 모델 아이템 생성은 성공하지 않았다. 새 마이그레이션·비밀값 변경·차단 우회는 없었다.
- 공통 하네스 피드백: 이전 구현에서 원천 자료의 역할·집계 범위 검증 규칙을 이미 반영했다. 이번 배포에서 추가할 별도 재사용 규칙은 확인되지 않았다.

## 2026-09-06

- Radar의 장시간 후보 분석을 HTTP `waitUntil()`에서 Cloudflare Queue 소비자로 분리하기로 결정했다.
- D1 진행 집계, 최소 한 번 전달에 대한 멱등성, 세 번의 제한된 재시도와 15분 정체 복구를 스펙 003과 ADR 002에 기록했다.
- 운영 Queue 생산자·소비자 각 1개, 원격 마이그레이션 완료, Worker 버전 `3221d948-a554-4c76-8513-e9a30e52a444`, 실제 후보 3곳의 `completed · 3/3` D1 집계를 확인했다. 기존 정체 실행은 저장된 후보를 보존해 `partial · 2/3`으로 복구했다.

- 당근 초기 공개 페이지의 고객 후기·사장님 답글을 구분하여 프로그램 아이템을 도출하는 수동 실행을 스펙 004와 ADR 003으로 정의했다.
- 후기 원문 복사 응답과 존재하지 않는 근거 참조를 서버에서 거부하고, 초기 HTML 데이터의 고객/답글 역할 및 실제 수집 범위를 분리했다.
- 실제 일반 HTTP 수집은 고객 후기 8개·답글 5개·표시 전체 11개로 확인했다. 로컬 OpenAI 키가 없어 실제 모델 응답과 운영 Worker 실행은 미검증이다.
- 최종 로컬 `npm run verify`: 73개 회귀, 정적 빌드와 Worker dry-run 통과. 기존 마이그레이션을 적용한 메모리 SQLite에서 실행 잠금·실패 저장·재시작을 확인했고, 390/768/1440px Chromium에서 합성 성공·오류·진행 화면과 가로 넘침 없음·44px 조작 영역을 확인했다.

## 2026-09-11

- Kakao Summary v0.2.0의 공개 설명과 세 플랫폼 ZIP 설치 안내를 스펙 005로 추가했다. macOS 15 이상 지원, Windows 진단·이력 조회 전용, API 키 메모리 보관과 로컬 이력 경계를 초기 HTML과 동적 화면에 반영했다.
- 제품별 상세 설명과 활성화 필요 여부를 metadata로 선언하여 AutoTrip 전용 결제·제품키 안내가 새 앱에 표시되지 않도록 했다. 인증 endpoint는 실제 연결 검증 전 `null`이다.
- `npm run verify` 75개 회귀·빌드·Worker dry-run, Abalone static audit·5개 도구 테스트, 390/768/1440px Chromium 6개 화면의 가로 넘침 없음과 제출 차단을 확인했다. source push·공개 배포·실제 다운로드는 별도 상태다.

2026-09-11 배포 전 상태: 원본 v0.2.0 ZIP은 독립 downloads 저장소에서 private R2 read-back과 current feed까지 검증했다. 이 showcase의 `npm run deploy`는 자동 승인 검토가 최초 요청만으로 공개 게시 확인이 부족하다고 판단해 실행 전에 거부했다. 공개 게시 및 최초 설치 코드 설정 승인을 요청한 상태이며 authEndpoint는 null이다. main push가 legacy Pages 게시를 유발하므로 승인 전에는 로컬 커밋만 보관한다.
