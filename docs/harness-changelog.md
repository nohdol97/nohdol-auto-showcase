# 프로젝트 하네스 변경 기록

## 2026-09-06

- Radar의 장시간 후보 분석을 HTTP `waitUntil()`에서 Cloudflare Queue 소비자로 분리하기로 결정했다.
- D1 진행 집계, 최소 한 번 전달에 대한 멱등성, 세 번의 제한된 재시도와 15분 정체 복구를 스펙 003과 ADR 002에 기록했다.
- 운영 Queue 생산자·소비자 각 1개, 원격 마이그레이션 완료, Worker 버전 `3221d948-a554-4c76-8513-e9a30e52a444`, 실제 후보 3곳의 `completed · 3/3` D1 집계를 확인했다. 기존 정체 실행은 저장된 후보를 보존해 `partial · 2/3`으로 복구했다.

- 당근 초기 공개 페이지의 고객 후기·사장님 답글을 구분하여 프로그램 아이템을 도출하는 수동 실행을 스펙 004와 ADR 003으로 정의했다.
- 후기 원문 복사 응답과 존재하지 않는 근거 참조를 서버에서 거부하고, 초기 HTML 데이터의 고객/답글 역할 및 실제 수집 범위를 분리했다.
- 실제 일반 HTTP 수집은 고객 후기 8개·답글 5개·표시 전체 11개로 확인했다. 로컬 OpenAI 키가 없어 실제 모델 응답과 운영 Worker 실행은 미검증이다.
- 최종 로컬 `npm run verify`: 73개 회귀, 정적 빌드와 Worker dry-run 통과. 기존 마이그레이션을 적용한 메모리 SQLite에서 실행 잠금·실패 저장·재시작을 확인했고, 390/768/1440px Chromium에서 합성 성공·오류·진행 화면과 가로 넘침 없음·44px 조작 영역을 확인했다.
